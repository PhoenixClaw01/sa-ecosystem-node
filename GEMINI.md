# Star Atlas ecosystem node

This extension connects Gemini CLI to the public, read-only Star Atlas ecosystem MCP.

- Live endpoint: https://sa-ecosystem-node-dashboard.vercel.app/api/mcp
- 24 read-only tools for fleets, star systems, DAO treasury and proposals, and signed community hub records
- No sign-in, no API key, and no wallet
- The server does not sign and does not write to any chain
- Official MCP Registry: `io.github.PhoenixClaw01/sa-ecosystem-node@1.0.3`

List the tools first, then call one read. This is not an ATMTA product. See [PLUG-IN.md](PLUG-IN.md) and the tool table in [README.md](README.md).
