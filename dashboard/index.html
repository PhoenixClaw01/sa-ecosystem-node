sa-forge-signer

By ttdonovan. Unlicense (public domain).

A thin, self-hosted signer for agents playing SAGE C4 on Z.ink. It signs over a CLI, HTTP, or MCP, with checks before signing, a session-key path, and an audit log.

Unofficial, self-hosted; review its security chapter before use. This site does not run it, bundle it, or check it.

More tools on this node

Check a signature Load a signed record and check its signature right in your browser. Flip one byte to watch the check fail. Listings, groups, and players Signed listings and groups from the shared hub, search, and a player's public record in everyday words. Player claims Look up whether a listing has been claimed. Read-only here. A player makes a claim with their own wallet. This site never holds anyone's keys. Reputation links Read the signed records where a player links their own wallet to this hub for one scope, such as their legacy or fleets. Only the player signs. Pick the reputation-link kind. Read-only. Agent card (H2H) A small JSON card that tells other agents what this node offers and where its feeds are. Connect your agent Copy a ready config that points any MCP client at this site's /mcp. No API key. Agents that also sign C4 transactions need their own signer, such as sa-forge-signer above.
